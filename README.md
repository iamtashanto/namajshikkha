# নামাজ শিক্ষা — Namaj Shikkha

[![Next.js](https://img.shields.io/badge/Next.js-15-black?style=flat-square&logo=next.js)](https://nextjs.org/)
[![React](https://img.shields.io/badge/React-19-blue?style=flat-square&logo=react)](https://reactjs.org/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5-blue?style=flat-square&logo=typescript)](https://www.typescriptlang.org/)
[![PWA](https://img.shields.io/badge/PWA-Supported-green?style=flat-square&logo=progressive-web-apps)](https://web.dev/progressive-web-apps/)

**Namaj Shikkha** is a modern, feature-rich Islamic educational platform designed to help users learn the correct methods of prayer (Salah), read the Quran, and access authentic Hadiths and FAQs. Built with a focus on speed, design, and accessibility.

🔗 **Live Link:** [namajshikkha.vercel.app](https://namajshikkha.vercel.app)

## ✨ Key Features

###  Prayer (নামাজ)
- **Detailed Prayer Rules**: Step-by-step guidance for Farz, Sunnat, and Nafal prayers.
- **Special Prayers**: Rules for Janaza, Eid, and Tahajjud prayers.
- **Prayer Details**: Comprehensive information about Rakats, Niyats, and Tasbeehs.

### 📖 Quran & Surahs (কুরআন ও সূরা)
- **Full Quran Library**: Clean and readable Arabic text with Bengali meaning.
- **Surah & Dua Section**: A collection of essential Surahs and Duas for daily life.
- **Pronunciation & Translation**: High-quality Bengali pronunciation for every verse.

### 🎧 Advanced Audio System
- **Global Playback**: Listen to Surahs while browsing any part of the site.
- **Playlist Navigation**: Skip forward/backward through Surahs in a category.
- **Auto-Next**: Automatically plays the next track in the playlist.

### � Islamic History & Knowledge
- **Islamic Eras**: Learn about pre-Islamic society, the life of the Prophet (PBUH), and the Caliphates.
- **Hadith & FAQ**: A large database of authenticated Hadiths and common Islamic questions.

### 📱 Modern PWA Experience
- **Installable App**: Save to your home screen directly from the browser.
- **Offline Mode**: Access core content even without an internet connection.
- **Responsive Design**: Optimized for all screen sizes, from mobile to desktop.
- **Dark Mode**: High-quality dark theme for better reading at night.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Library**: [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites
- Node.js 18.x or higher
- npm or pnpm

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/mdtanvirahamedshanto/namajshikkha.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
